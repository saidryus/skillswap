## Google Forms Setup Guide
*For whoever builds the form — do this before testing day.*

This survey uses **section branching** so participants only see questions relevant to their role. Set it up as follows:

| Section | Questions | Shown to |
|---|---|---|
| Section 1 | Q1 (role) + Q2 + Q3 | Everyone |
| Section 2 | Q4T + Q5T (Tutee) | Tutee only |
| Section 3 | Q4U + Q5U (Tutor) | Tutor only |
| Section 4 | Q4A + Q5A (Admin) | Admin only |
| Section 5 | Q6 + Q7 + Q8 | Everyone |

**To enable branching:** On Question 1, click the three dots (⋮) at the bottom right → **"Go to section based on answer"** → set:
- Student (Tutee) → Section 2
- Student (Tutor) → Section 3
- Administrator → Section 4

At the end of Sections 2, 3, and 4, set **"Continue to next section"** so everyone lands on Section 5.

All questions except Q1 should be set to **Paragraph** (long answer) type.

Turn off **"Collect email addresses"** to protect participant confidentiality.
